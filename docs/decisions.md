| 32 | 2026-10-22 | Pull cursor uses the writing transaction's ID (`xid8`), bounded by the oldest running transaction; supersedes row 20 | Sequence with a 30-second safety window; logical replication | A sequence can be handed out in one order and committed in another, so a reader can step past a row that isn't visible yet and miss it forever. The window is a guess and delays every sync; replication is far too heavy for one writer per user | A long-running transaction stalls pulls noticeably | Decided |
| 31 | 2026-10-22 | Guard each catalog import: reject the whole file if it fails shape checks, shrinks below 90% of the active catalog, would retire over 2% of active rows, or would rename/regroup over 5% of existing rows | Trust the file; rely on database backups to undo a bad import | A truncated or malformed download would otherwise retire or rewrite the catalog players' sessions point at.
